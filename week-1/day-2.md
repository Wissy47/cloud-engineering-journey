# Day 2 — Linux Networking, IP Addresses, Ports & SSH

Understand how Linux networking works and practice diagnosing connectivity using IP addresses, routes, DNS, ports, SSH, and simple network tools.

- Network interfaces
- Routing tables
- Default gateway
- DNS resolution
- Common ports
- TCP vs UDP
- SSH
- Netcat
- HTTP connectivity
- Neighbor tables
- Basic network troubleshooting
