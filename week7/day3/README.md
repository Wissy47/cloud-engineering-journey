# Week 7 Day 3 — Advanced Amazon S3

## Objective

Practice advanced S3 access and storage features using floci.

## Environment

- AWS CLI
- floci
- Region: us-east-1
- Endpoint: http://localhost:4566

## Concepts Learned

- Bucket policies
- IAM policy vs bucket policy
- Public Access Block
- Presigned URLs
- Temporary object access
- Static website hosting
- S3 storage classes
- Lifecycle transitions

### Static Website
